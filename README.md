# Society Khata Web

Next.js 14 + RTK Query frontend for Society Khata.

## Backend repo

https://github.com/mubashirhussan/society-khata-api

## Run locally

```bash
cp .env.example .env.local   # if present, or create .env.local
# NEXT_PUBLIC_API_URL=http://localhost:5084/api

npm install
npm run dev
```

App: http://localhost:3000

## Stack

- Next.js App Router
- Redux Toolkit Query
- Tailwind CSS
- Role / permission-based UI
